# decisions/

Decision log. Decisions are made by the CEO only. Agents may transcribe a decision the CEO stated in-session, never invent one.

One file per decision: `YYYY-MM-DD-<short-slug>.md`

```markdown
# <Decision title>
- Date: YYYY-MM-DD
- Decision: <what was decided>
- Reason: <why; link evidence in research/ or interviews/>
- Alternatives considered: <optional>
- Revisit if: <optional trigger>
```
